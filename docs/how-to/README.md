# Guide pratiche

Istruzioni orientate a un compito per chi conosce già il prodotto. Questa sezione è
predisposta; le procedure verranno aggiunte quando potranno essere provate.

Compiti previsti: configurare CPU/GPU o un provider remoto; convertire scansioni
multilingua; revisionare formule; esportare e recuperare conversioni; effettuare
backup e ripristino; aggiungere un adattatore; eseguire i benchmark di sviluppo.
