# Materiale locale conservato e limiti dell'archivio

Archivio selettivo di decisioni, report, manifest e ricevute pubbliche/sintetiche.
Non è un backup eseguibile completo della run: cache, interpreti, prefix installati,
immagini Docker, wheel/sdist pubblici e payload/fixture non selezionati rimangono
locali. Nessun file è stato eliminato. Non attribuire un nuovo PASS a una receipt
storica né eseguire automaticamente gli script archiviati, che sono dati storici;
diagnostici/test permanenti sono nei percorsi versionati del prodotto.

I riferimenti non selezionati dei report sono esplicitamente marcati e rimandano
qui. Elenco macchina leggibile in omitted-local-references.json; percorsi di
provenienza e hash degli oggetti copiati in archive-files.json. Gli assoluti nei
JSON sono provenienza dell'esecuzione originale, non configurazione portabile.

Conservare l'intera run locale, le cache, i prefix e gli oggetti Docker fino
all'integrazione verificata e a una decisione di pulizia selettiva. Questo
archivio non autorizza rm/git clean/prune né afferma che tutti i4245 payload
identificati dallo snapshot siano presenti qui. Le tre impronte di review sono
conservate integralmente; l'archiviazione non modifica il loro significato.
